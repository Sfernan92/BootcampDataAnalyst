1. Un comando que ahora entiendo y que antes no conocía.

python -m pip install ipykernel. Sirve para instalar el paquete que permite conectar Jupyter con nuestro entorno de Python y ejecutar las celdas del notebook.

2. Un error que hemos resuelto y cómo lo hemos diagnosticado.

Tuvimos un problema al seleccionar el kernel porque VS Code mostraba el error Failed to install the Python Extension. Lo diagnosticamos entrando en el apartado de extensiones, comprobando la instalación de Python y solucionando el problema antes de seleccionar nuestro entorno .venv.

3. Una diferencia entre archivo, código, dato y resultado.

Un archivo es un documento que almacena información; el código son las instrucciones que ejecutamos para procesarla; un dato es cada pieza de información que utilizamos, y un resultado es lo que obtenemos después de ejecutar el código sobre esos datos.

4. Una cosa que el CSV no permite afirmar del negocio.

No podemos conocer cuántos jugadores únicos han realizado operaciones ni calcular los beneficios reales del juego, porque no tenemos información suficiente sobre los jugadores ni sobre los costes.
