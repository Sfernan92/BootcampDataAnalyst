
# Mapa del editor

## Herramientas

- VS Code: editor utilizado para trabajar con el proyecto.
- Python: lenguaje de programación que utilizaremos para analizar datos.

## Organización del proyecto

- datos/: contiene los archivos de datos que utilizaremos.
- scripts/: contiene el código y los programas.
- notebooks/: contiene los cuadernos donde podemos trabajar y analizar datos.

## Aprendizaje

He aprendido que VS Code permite trabajar con todo un proyecto desde un mismo entorno, utilizando un editor, una terminal y extensiones.
